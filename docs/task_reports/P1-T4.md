## Implementation / Frozen Artifact

唯一新增正式 research artifact 是 `erc20-research/abstract-propagation/v1`，owner 为 `scripts/s_seir/s_seir_research_propagation.py`。`propagate_regions(sfir_payload, upstream_result, contract, *, resource_limits=...)` 先直接调用 P1-T3 `validate_contract` 与 `consume_regions`，再为每个 consumable P1-T2 region 产生一个 artifact；result wrapper 的 `intake_outcome / propagations / evidence_records / status / intake` 只是 driver 返回结构，不是第二个 artifact。

Frozen payload 顶层恰为六项：

| 字段 | 实际 nested representation |
| --- | --- |
| `region_ref` | 原 P1-T2 `FlattenedRegion.id`。 |
| `domain_ref` | 原 P1-T3 `AbstractDomainContract.id`。 |
| `node_context_states` | canonical list；每项恰为 `node_ref / context / state / status / evidence_refs`。`state` 是该 CFG block 执行 node-local transfer **之前**的最终 incoming `AbstractState`；只保存 reached cache entries，entry 缺失表示 unreached，绝不表示 UNKNOWN。 |
| `convergence_evidence` | engine/config refs、cache/state phase、原 entries seed scope、确定性统计、final/UNKNOWN node-context counts、worklist drained/frontier、termination reason、inherited status/diagnostics、明确的 non-claims。 |
| `resource_budget` | `policy / limits / used / cutoff`；只使用确定性计数器。 |
| `termination` | 仅 `FIXED_POINT / RESOURCE_LIMIT / UNSUPPORTED / ERROR`。 |

Artifact identity 为 `stable_identity('abstract-propagation', {region_ref, domain_ref, config})`。`config` 恰含 domain ref、显式 resource limits、固定 scheduling policy 与 incoming-state cache phase；不含 queue 位置、iteration/pop count、object id、wall clock 或最终统计。artifact envelope、payload、state/context、frontier 与 evidence 全部经 shared canonical JSON 规则规范化。相同 region/domain/config 重复运行及 blocks/edges/cases/candidates/semantic node collection 重排得到相同 artifact；不同 resource limits 得到不同 identity。一次 semantic occurrence 不按值 hash 去重。

### Propagation config / resource budget

调用者必须显式提供且由 `normalize_resource_limits` 验证以下四个非负/正数计数器，没有隐式默认值：

- `max_processed_items >= 0`
- `max_cache_entries >= 1`
- `max_contributions >= 1`
- `max_requeues >= 0`

调度固定为 canonical seeds + canonical outgoing Fact CFG edges + FIFO + queued-key coalescing。resource budget 只是 safety guard；任一计数器触发即 `RESOURCE_LIMIT`，保留已形成的 canonical cache、cutoff counter/limit 和 queued/pending frontier。没有 wall-clock 语义终止条件。

### Fixed-point semantics

Cache semantic key 是 `(region_ref, node_ref, canonical KSwitchContext)`；同一 node/context 恰有一个 entry，不同 context 从不预先合并。初始化对 P1-T2 所有 `entries` 作 canonical seeding，state/context 直接来自 `consume_regions`，不从 case label 猜初值，也不选择某个多入口。

每次 pop 读取 existing block `semantic_ids` 作为 SFIR 已建立的 block 内语义顺序。只有 occurrence 与 candidate SourceRef 匹配且现有 FactSSA/raw write evidence 明确关联的 fact 才调用 P1-T3 `local_transfer`；ordinary/unrelated fact 是 identity。copy/Binary operand 只按当前 fact 已有 typed Slither operand与唯一 FactSSA binding 显式映射到 region candidate，不运行 RD/Def-Use/VFG。多个相关 write 缺完整稳定 block order 时，用 P1-T3 `unknown` 构造保守 UNKNOWN 并记录 `INSUFFICIENT_EVIDENCE`，不新增 order recovery。Unsupported local operation继续沿用 P1-T3 UNKNOWN，不转成 engine UNSUPPORTED。

Traversal 只使用对应 function 的现有 Fact CFG：core 内边及 P1-T2 明确 exits 的 boundary target。ordinary edge 原样保留 context；只有与 `cases[*].edge_ref` locator 完整匹配的 CFG edge 调用 P1-T3 `update_context`。`target_ref`、`RETURNS_TO_DISPATCHER`、case guard 均不用于 feasibility 或 real-successor 判定。convergence evidence 明确记录 `real_successor=false / guard=false / feasibility=false / solver_outcome=NOT_RUN`。

Incoming contribution 只与相同 cache key 调 P1-T3 `join_states`，并以 `state_leq` 校验 upper bound、以 `stabilized` 判定变化；只有 canonical state 真正新增信息且 key 当前不在 queue 时 re-enqueue。counter/trace 只在 convergence/resource evidence，绝不进入 AbstractState。

`FIXED_POINT` 的精确定义是：所有 seed/edge contributions 已处理，queue drained，没有 pending frontier，没有 resource cutoff 或 engine-level failure，且 cache 更新均已按 P1-T3 stabilization 处理。UNKNOWN AbstractValue 可继续传播并以 `FIXED_POINT` 收尾，但 artifact shared status 仍保留 UNKNOWN/PARTIAL diagnostics。`UNSUPPORTED` 只表示继续传播所需的 SFIR/region construct 不可安全处理；`ERROR` 表示 contract/invariant/unexpected implementation failure；两者均不伪装成 UNKNOWN。上游 BOUND+PARTIAL 可局部 FIXED_POINT，但 inherited status 和 artifact completion 保持 PARTIAL。

### Intake and API

- `NO_REGION`：返回零 propagations，intake completion 保持 COMPLETE，不伪造 per-region artifact。
- `NO_CONSUMABLE_REGION`：返回零 propagations，完整保留 P1-T2/P1-T3 PARTIAL/UNSUPPORTED diagnostics。
- `BOUND`：逐 binding 保守传播；输入 `FlattenedRegion`、domain、SFIR 均不修改。
- 输入 domain/fingerprint/frozen contract violation 在 intake 前显式抛 `ContractValidationError`；有效 binding 之后的 engine unsupported/invariant/unexpected failure分别映射成该 region 的 UNSUPPORTED/ERROR artifact。

公开 API：`normalize_resource_limits / propagate_regions / validate_propagation / node_context_states / query_node_context_state / validate_result_evidence`。后两项查询只投影既有 canonical cache，不推导 endpoint、successor、Guard 或 feasibility。

没有修改 P1-T2/P1-T3 或其他 production source；没有需要本 Task direct-upstream compatibility fix，也没有冻结 schema/identity/domain semantics 变更或新 ADR。

## P1-T5 Handoff

P1-T5 可直接 import：

```python
from s_seir_research_propagation import (
    propagate_regions, validate_propagation,
    node_context_states, query_node_context_state,
)

result = propagate_regions(
    sfir_payload, p1_t2_result, p1_t3_contract,
    resource_limits={
        "max_processed_items": 10000,
        "max_cache_entries": 10000,
        "max_contributions": 100000,
        "max_requeues": 100000,
    },
)
for propagation in result["propagations"]:
    validate_propagation(propagation, region=region, contract=p1_t3_contract)
    if propagation["payload"]["termination"] == "FIXED_POINT":
        entries = node_context_states(propagation)
```

在消费前必须先检查 result `intake_outcome/status`、每个 artifact `termination/status` 与 inherited diagnostics。`FIXED_POINT` 只承诺当前结构 scope/node-context cache 已 drain/stabilize，不承诺 state 非 UNKNOWN、边可行或上游全局 COMPLETE。`RESOURCE_LIMIT` 的 cache 是 partial，frontier 在 `convergence_evidence.worklist.frontier`；UNSUPPORTED/ERROR 不可当空结果。entry 缺失表示 unreached，entry 存在且 `state.values[*].tag=UNKNOWN` 表示 reached 但抽象证据不足。

`node_context_states` 每项的 `state` 是 incoming-before-node-transfer state；精确查找用 `query_node_context_state(propagation, node_ref, context)`，返回 entry 或 `None`。P1-T5 应把同一 node 的不同 KSwitchContext 保持分离，仅在现有 artifact/cache 语义允许时读取；不得丢 context 后合并。

Entry seeding 来自原 P1-T2 `entries`。ordinary Fact CFG edge 不改变 context；只有与 `cases[*].edge_ref` 明确匹配的 observed dispatcher arm 才 append/truncate context。context history 是 structural observation，不是真实 successor。P1-T3 的实际调用路径为 `local_transfer` → same-key `join_states` → `state_leq/stabilized`，并由 `update_context` 处理 observed arm；没有第二套 domain rules。

Known limitations：只传播 P1-T2 可消费 flattened region 的 core 与明确 exit boundary；主线缺 typed operand、unsupported local op、checked overflow 与不可靠 in-block order 保守 UNKNOWN；不运行 Guard/path feasibility，因而所有 structural outgoing edges 都是 carrier；resource limits 必须由调用者配置；不提供 post-node state cache，P1-T5 如需候选 endpoint transition，应依据 frozen direct-input contract消费 incoming node/context state与现有 SFIR fact，而不能把结构遍历当 real successor。

本 Task 没有生成 Candidate SemanticControlEdge、endpoint reconstruction、real successor、Guard、SAT/UNSAT、symbolic/SMT、Module 2/3 artifact。P1-T5 必须在独立授权后开始。
