## Detection Rule and Boundary

detector 使用普通 CFG structural algorithm：构造 supplied Fact CFG adjacency、SCC、受限 reachability 与 structural entry/exit。一个正式候选至少同时具备：

1. explicit case/default switch，或至少三个不同 target 的等价多分支；
2. 至少两个观察到的 dispatch arms 在同一 SCC 内结构性返回 dispatcher；
3. dispatcher condition node 的现有 SFIR read/FactSSA binding 与 region 内 assignment/write evidence 有局部精确关联；
4. 单一可安全划定的 cyclic region，且有 structural exit/terminal relation。

这不是 feasibility、真实 successor、Guard 或 execution-order 结论。普通 acyclic business switch 是合法 no-region；普通二分支 loop 和 branch/join 不会因单一 back-edge/loop/switch 特征命中。fake/transport/unrelated blocks 只要属于候选 SCC 可保留在 region，不因没有 action 删除。

Control-state candidate 只保存已有 condition context、semantic-node reads/writes、FactSSA/binding refs、placement 和 provenance。没有跨 CFG propagation、Def-Use、RD、VFG、AbstractState、transfer/join、worklist/fixed point、symbolic execution 或 SMT。

## Frozen `FlattenedRegion`

schema 为 `erc20-research/flattened-region/v1`，继承 shared `ArtifactEnvelope/EvidenceRecord/SourceRef/AnalysisStatus`。payload 严格且仅包含：

- `dispatcher_ref`
- `region_cfg_refs`
- `control_state_candidates`
- `cases`
- `entries`
- `exits`
- `detection_evidence`

没有 `action_refs`，也没有额外正式 `Dispatcher`、`DispatcherStateCandidate`、`Case`、`RegionEntry` 或 `RegionExit` artifact。`cases` 只记录 supplied Fact CFG 中 dispatcher 的直接 outgoing arms 及其 immediate target；`RETURNS_TO_DISPATCHER` 只是结构 reachability evidence，不是推导真实 successor。

identity 严格由 `CFG origin set + dispatcher occurrence` 的 canonical JSON 产生，不使用 list/traversal index、Python object id、随机 UUID、变量名、semantic/action id 或 source/list order。Fact CFG block/edge/semantic id 只出现在 `SourceRef.locator`。collection reorder targeted regression 保持同一 `FlattenedRegion.id`。

Artifact status 为 `proof=CANDIDATE`、`completion=COMPLETE`、`solver=NOT_RUN`。未建立 HIGH/MEDIUM/LOW 或数值 confidence。Evidence 分别记录 multi-arm/returning-arm structure、existing local read/write candidate、entry/exit boundary，以及 region 内 action control anchors。

## SemanticAction Consumption

P1-T2 调用 P1-T1 validator 并直接读取：

- `result["actions"]` 与 `action["id"]`；
- `payload.semantic_ref/control_anchor/replacement_refs`；
- action `evidence_refs/status`；
- result `coverage/unresolved_diagnostics/status`。

`action_input.observations` 是只读输入审计，不是第二套 action collection，也不产生语义效果。关联规则保持为：

`SemanticAction.control_anchor → CFG block → FlattenedRegion.region_cfg_refs`

region detection evidence 可在 `artifact_refs` 引用已存在 action id；frozen payload 不增加 `action_refs`。unanchored actions、UNRESOLVED coverage 和 diagnostics 均保留并使 result `PARTIAL`，不会删除 action、标 unreachable/infeasible 或重复计算 replacement。

## Conservative Outcomes

- 无回返 arm 的 ordinary switch：合法 no-region，scan 可 `COMPLETE`。
- 只有一个回返 arm，或多个回返 arm但缺 condition read/write association：`INSUFFICIENT_EVIDENCE/PARTIAL`，不产 region。
- 同一 cyclic component 有多个可信 dispatcher：ambiguous，`INSUFFICIENT_EVIDENCE/PARTIAL`。
- cyclic candidate 有多个外部 entry target：按当前范围视为 irreducible，`UNSUPPORTED/PARTIAL`。
- cyclic candidate 无 CFG exit 且无 terminal：`UNSUPPORTED/PARTIAL`。
- non-SFIR/standalone Yul object：`UNSUPPORTED/PARTIAL`；未新增 frontend。

以上不是“证明没有 flattening”。No-region 不删除函数或 actions。
