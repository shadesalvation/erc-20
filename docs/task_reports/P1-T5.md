### Identity / canonical dedupe

Identity basis 恰为 `from + to + region_ref + context_ref + path_alternative`。`path_alternative` 保存 origin、ordered carrier block/edge refs、structural branch-arm alternative refs、same-block local relation evidence、region boundary transitions。完整 basis 持久化在该 edge 唯一 EvidenceRecord 的 `result.identity_basis`；collection validator 由此重算 id。只有完整 basis 相同才按 id canonical dedupe。action occurrence identity直接复用 `SemanticAction.id`，绝不按 kind/payload 合并；不同 context 或 branch alternative 保持不同候选。所有输入 collection 重排后 edge ids、canonical result accounting 不变。

为了让循环有限且不依赖任意 cutoff，搜索状态键为 `(CFG location, semantic endpoint boundary/cursor, mode/region, exact KSwitchContext, finite branch-alternative ref set)`。重复绕同一 loop arm 不因迭代次数产生新的“直接 successor alternative”；不同 branch arm/context 仍分离。队列与 CFG/cache alternatives 均 canonical 排序，首次 witness 是确定性的。

### First-next semantic compression

对 ENTRY 与每个 anchored SemanticAction source 分别搜索：carrier/fake/dispatcher/intermediate blocks可穿过；同一 structural/context alternative 首次遇到下一个 SemanticAction 或 EXIT 即 emit 并停止该 alternative。A→B→C 因而只有 A→B 与 B→C，不用一般 reachability再制造 A→C。branch产生多个 first-next，join允许多个 source 指向同一 target；loop re-entry可形成 back/self candidate。

同 block action只在 block `semantic_ids` 对所有相关 occurrence 完整且唯一时使用现有 SFIR 已声明的 canonical local execution order。缺失/重复时不按 action id、source span 或 collection order排序：ENTRY可指向任一 first action，每个 source保留其他同块 action及“source may be last”的 CFG continuation alternative，并记录 `AMBIGUOUS_LOCAL_ACTION_ORDER / INSUFFICIENT_EVIDENCE`。

### Flattened / normal / mixed scopes

- Normal：仅用现有 Fact CFG 与 supplied SemanticAction anchors；不创建 region 或 propagation。合法 `regions=[]` 仍恢复 ENTRY/action/EXIT candidates。
- Flattened：只遍历 P1-T2 core/explicit exit boundary，且每个位置必须有 P1-T4 reached node/context cache entry。ordinary edge要求 exact same context cache entry；observed dispatcher arm只匹配 target cache 中末尾 `arm_ref` 对应该 case 的 contexts。这是 high-recall carrier evidence，不是真实 successor证明。
- Mixed：normal traversal到 region core时切换到 matching P1-T4 cache；region exit boundary处理完 first-next action后恢复 normal traversal。region core内不会同时运行无 context normal path。

P1-T4 state 明确按 `INCOMING_BEFORE_NODE_TRANSFER` 消费；candidate evidence premise 也记录该 cache phase。本 Task 不调用 transfer/join/update_context，不重跑 detector/domain/fixed point。

### Status / evidence / accounting

每条 candidate 的 EvidenceRecord 包含 source/target occurrence或 boundary SourceRefs、ordered carrier CFG refs、region/propagation/action artifact refs、精确 node/context refs、path alternative、unrefined condition refs、`solver_outcome=NOT_RUN`。`validate_candidate_collection` 校验 edge→evidence closure、identity basis、action/region/propagation解析、每个 node/context ref确实存在于 P1-T4 cache，以及 accounting 可复算。

- `FIXED_POINT` 只允许使用稳定 cache，不升级 feasibility；cache state UNKNOWN仍生成结构候选并保留 PARTIAL diagnostics。
- cache entry缺失是该 propagation/context unreached；不会伪造 UNKNOWN entry。
- `RESOURCE_LIMIT` 只消费已有 cache，输出 covered candidates；exact worklist frontier进入 per-function accounting，scope 标 `partial=true / truncated=true`。
- `UNSUPPORTED/ERROR` 无 cache时不伪造 region candidate，affected scope 显式 unresolved且 result保持 PARTIAL。
- action/region/propagation upstream PARTIAL 均进入 function accounting与 result status；unanchored action不猜 endpoint。
- 无 action但 CFG 有可连接 ENTRY/EXIT 是合法 `ENTRY→EXIT` COMPLETE；缺 CFG entry等证据失败与该情形分开诊断。

Per-function accounting 保存 input action occurrence count、ENTRY/EXIT block scope、flattened/normal/mixed counts、unresolved scopes、partial/truncated flags、P1-T4 frontier以及 emitted candidate ids。它是可复算 machine evidence，不进入 frozen edge payload。

## P1-T6 Handoff

P1-T6 必须直接 import上述 API和读取 `result["edges"]`；不得重新做 candidate endpoint reconstruction。实际 schema/file为：`scripts/s_seir/s_seir_research_control_edges.py` / `erc20-research/semantic-control-edge/v1`；frozen payload七字段为 `from / to / candidate_id / guard_ref / context_ref / feasibility / region_ref`。

Endpoint：ACTION用 `SemanticAction.id` occurrence ref；ENTRY/EXIT用带完整 frozen `function_ref` 的边界对象。candidate identity/dedupe依据为 endpoints + region/context +完整 path-alternative provenance；同 id才可合并。

P1-T6 定位每条 local refinement scope 的最小方法：

1. 由 edge `evidence_refs[0]` 在 `result["evidence_records"]` 取唯一 EvidenceRecord。
2. `record.result.carrier` 给出 ordered carrier block/edge witness、branch alternative、same-block relation与 region boundary transitions；`record.source_refs` 是可解析 SFIR occurrence/CFG refs。
3. flattened/mixed edge由 `payload.region_ref` 定位原 FlattenedRegion；`payload.context_ref.propagation_ref` 定位原 AbstractPropagation，`node_context_refs` 可直接交给 P1-T4 `query_node_context_state` 复核 exact incoming state/context。不要丢 context 后合并。
4. `record.result.propagation_node_context_refs` 与 artifact refs 界定 abstract scope；P1-T6 只需在该 candidate carrier/context内做局部 symbolic refinement。
5. `payload.guard_ref` 与 `record.result.unrefined_condition_refs` 只给出现有 source predicate/CFG-edge evidence；P1-T6 可据此构造自己的 typed query/Guard，但不得把它们当 normalized Guard。
6. 当前所有 `payload.feasibility=UNRESOLVED`、status/evidence solver=`NOT_RUN`。P1-T6 refine时必须保留 candidate id作为 lineage，并按自己的 frozen refined-edge/SolverEvidence contract记录 SAT/UNSAT/UNKNOWN/TIMEOUT/UNSUPPORTED。

RESOURCE_LIMIT：只 refinement已 emit且有 cache证据的 candidates；accounting中的 exact frontier与 TRUNCATED scope必须保留，未探索部分不能当 rejected/absent。FIXED_POINT+UNKNOWN：可以 refine但不可把 fixed point当 feasible。UNSUPPORTED/ERROR/upstream PARTIAL：读取 edge status、function accounting与 `unresolved_scopes`，不得把无 candidate解释为 infeasible。

Known limitations：R1 source support仍 insufficient；本工程适配不声称论文具体 edge algorithm/default k。P1-T4没有逐 contribution transition lineage，所以 observed arm按 target cache末尾 arm ref匹配，ordinary edge按 exact context匹配，仍是高召回 over-approximation。branch alternative把重复同一 loop arm视为同一直接-successor alternative，不按迭代次数复制候选。一个 direct carrier若无 semantic endpoint边界而跨多个不同 FlattenedRegion，目前显式 `MULTI_REGION_CARRIER/UNSUPPORTED`，不静默拼接不兼容的单一 `region_ref/context_ref`。同块顺序只信完整唯一 SFIR `semantic_ids`；否则输出歧义候选。`guard_ref` 未做逻辑合取、等价、规范化或 feasibility解释。
