### 决策与实现

[ADR P0-T1-001](../decisions/P0-T1-001-baseline-semantic-contracts.md) 记录契约依据：StateWrite 正确消费 SSA 值 `value_1`，不能为满足旧文本断言去掉 SSA；最终 CFG 已保留 Guard，不能仅凭兼容 facts 上的 condition 是否重复出现判定丢失。

- 更新 StateWrite 旧断言为精确 SSA 值一致，并检查最终唯一写入、相同 storage location、参数 entry definition；既有禁止重复展开调用的集成回归保留。
- Guard 测试增强为最终真假边可达性、返回汇合、唯一 Yul 赋值、比较到 BranchCondition 数据边及 path witness 检查。
- 加强检查发现实际错误：具名常量 FIXED 被 Slither serializer 错标为 state read。修正声明常量标记，lifter 保留名称、canonical name、类型与 initializer 文本，不产生运行时 SSA 读取。加入同名可变 storage 的反例及具名 string 常量检查。新增检查在修复前确实失败于虚假 StateRead，见 `before/strengthened_guard_test.log`。
- 首个失败修正后，atomic_ops 的未到达断言暴露兼容 bridge 不读已存在 semantic provenance，退回 slot 证据位置。修复为优先采用现有 CFG anchor，保留全部原 endpoint 和顺序断言；新增不含 effects transport、节点编号和输入次序均与 CFG 顺序不一致的回归。

修改现有源码共 6 文件：`scripts/s_seir/s_seir_control_builder.py`、`s_seir_solidity_semantic_lifter.py`、`s_seir_semantic_fact_bridge.py` 及 `s_seir_solidity_atomic_ops_tests.py`、`s_seir_solidity_slithir_tests.py`、`s_seir_semantic_fact_bridge_tests.py`。前三者是局部分类/连接修复，后三者为测试；不重设计 SFIR、CFG、MemorySSA 或 SinkResolver。
