# 08 Yul Object、ERC-20 Selector 分发

本样例覆盖：

- 独立 Yul `object`
- `code`、子 `object`、`data`
- `datasize`、`dataoffset`、`datacopy`
- Yul selector 分发
- `switch`、`case`、`default`
- `sload`、`sstore`、`mstore`、`keccak256`
- `calldataload`、`return`、`revert`
- `log3`
- ERC-20 常见函数：`totalSupply`、`balanceOf`、`allowance`、`transfer`、`approve`、`transferFrom`

入口对象：`yul/MiniERC20.yul`
