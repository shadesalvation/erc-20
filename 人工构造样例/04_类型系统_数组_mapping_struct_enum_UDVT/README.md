# 04 类型系统、数组、mapping、struct、enum、UDVT

本样例覆盖：

- 基础值类型：`bool`、`uint`、`int`、`address payable`、`bytesN`
- 动态 `bytes`、`string`
- 定长数组、动态数组
- 嵌套 mapping、带参数名的 mapping
- `struct`、`enum`
- 数据位置：`storage`、`memory`、`calldata`
- 函数类型
- 用户定义值类型 `type`
- 显式类型转换
- ERC-20 批量转账和快照记录

入口合约：`contracts/TypedSnapshotERC20.sol`
